## Publication and accuracy

This profile differentiates documented engineering projects from general solution capabilities. It does **not** imply that every repository feature has been verified in production. It does not include invented customers, performance metrics, testimonials, or medical outcomes.

No confidential internal project screenshots or customer information are included. Confirm project disclosure rights and current production status before distributing externally.

## Typography and design

- Persian edition: **Ravi Regular / Ravi Bold** embedded in the existing PDF.
- English edition: contemporary system sans-serif; Ravi is included for Persian text elements.
- Palette: forest green, deep navy, warm off-white.
- Print format: A4 portrait.

Font binaries are intentionally **not** included in this repository package. The embedded PDF is intended for viewing and sharing; regenerate HTML/PDF only if you have the proper font files and usage rights.

## Regenerating

`build_en.py` is included as a reproducibility reference; it expects the Ravi font files in `/mnt/data` and Playwright + Chromium installed. Adjust input font paths if building elsewhere. The HTML file can be edited directly without regenerating.
